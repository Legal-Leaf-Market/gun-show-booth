      Saving writes your changes straight to the site's GitHub repo, and the site updates about a minute later. Connect once per phone.

      How to get an access token
      1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
      2. Tap Generate new token. Set Resource owner to the account that owns this site's repo.
      3. Under Repository access, pick Only select repositories and choose this site's repo.
      4. Under Permissions, set Contents to Read and write. Leave everything else alone.
      5. Generate it, copy it, and paste it above. Set an expiry you'll remember, and make a new one when it runs out.
