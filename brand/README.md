## Notes and limitations
- All photos are illustrated stand-ins. Replace with real owner photographs.
- Legal label statement is a placeholder pending owner review.
- QR blocks are placeholders. Generate actual codes with the live website.
- Source SVGs use live text. Files ending `-outlined.svg` are currently layout-identical font-dependent copies, not actual glyph outlines. Convert fonts to paths in Illustrator or Inkscape before vendor production.
- Print SVGs are editable layout references, not print-certified bleed CMYK PDF/X deliverables. Set full-size trim, 0.125 inch bleed, 0.125 inch safety margin and printer crop marks with your print provider.
- Suggested Pantone orange: 1665 C. Suggested CMYK print profile: US Web Coated SWOP v2, subject to printer confirmation.
- Web raster sizes should be tested against deployment limits and compressed further where needed.
- Template assets contain placeholder fields until real event and contact details are supplied.
