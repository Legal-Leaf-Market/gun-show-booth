Things to ask on every call (from the report's open questions):

- Are sealed, labeled home-baked goods allowed, or does the building's
  kitchen or concession contract rule them out?
- Do you need a certificate of insurance from a single-table vendor?
- CIGS requires vendors to stay both days. Confirm teardown time.

When a show is booked, add it from the phone admin (Events tab). Set the
admission per event when it differs from the $6 default (Indy 1500 is $15
plus parking; the southern 1-day shows are $8).
